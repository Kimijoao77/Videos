# Política de privacidade do Nexus Canal

Atualizada em 9 de novembro de 2026.

O Nexus Canal é uma ferramenta pessoal que publica os vídeos dos canais do YouTube Aqui Há Dragões e Here Be
Dragons. Só o dono desses canais usa. Esta página explica que dados ela usa e o que faz com eles.

## Serviços de API do YouTube

O Nexus Canal usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os
[Termos de Serviço do YouTube](https://www.youtube.com/t/terms). A
[Política de Privacidade do Google](https://policies.google.com/privacy) também vale.

## O que ele acessa

Quando o dono conecta um canal, o Google pede duas permissões:

- **Gerenciar a conta do YouTube** (`youtube.force-ssl`): usada só para enviar os vídeos aprovados, colocar a
  capa, agendar, publicar ou deixar privado um vídeo, e para saber qual canal foi conectado.
- **Ver relatórios do YouTube Analytics** (`yt-analytics.readonly`): usada só para mostrar ao dono, no app, os
  números dos próprios canais.

O app não lê e-mails, contatos nem dados de outras pessoas, e não apaga vídeos.

## Onde os dados ficam

- A autorização do Google fica guardada como segredo criptografado no GitHub, e só o robô de postagem a usa. Ela
  não aparece no app, nas páginas nem nos registros.
- O que o robô registra (o link de cada vídeo, quando foi postado e se deu certo) fica num repositório privado do
  dono.
- A página do Nexus no computador guarda no seu navegador só a chave do GitHub que você mesmo digita e uma cópia dos
  dados para abrir mais rápido. Nenhum cookie de rastreamento é usado.

## Compartilhamento

Os dados não são vendidos, não servem para publicidade e não são passados a ninguém. Eles só vão para o próprio
YouTube, quando o dono manda postar.

O uso das informações recebidas das APIs do Google segue a
[Política de dados do usuário dos serviços de API do Google](https://developers.google.com/terms/api-services-user-data-policy),
incluindo os requisitos de uso limitado.

## Como tirar o acesso

A qualquer momento, em [myaccount.google.com/permissions](https://myaccount.google.com/permissions), escolha o app
e toque em **Remover acesso**. Os registros guardados são apagados a pedido do dono.
